# Дмитрий Пронин — двуязычный исследовательский сайт

Готовый статический сайт: `index.html` — английская главная, `ru/index.html` — русская. Для каждого из двух исследований есть отдельный разбор на обоих языках. Все страницы уже сгенерированы; сайт работает без сборки, базы данных и внешних библиотек.

## Изменения

- Тексты и ссылки находятся в `build.mjs`.
- Оформление — `assets/style.css`.
- Публичный адрес и добровольно выбранный email — в `site.json`. Поле email можно оставить пустым; в контактах уже указаны публичные Telegram и профиль ВШЭ.
- После изменения выполнить `node build.mjs` в этой папке. Требуется только Node.js, без установки пакетов.

## Публикация на GitHub Pages

1. В аккаунте DDPronin создать публичный репозиторий `DDPronin.github.io`, если такого репозитория ещё нет. Если есть — сначала сохранить и проверить его содержимое.
2. В `site.json` указать `"url": "https://ddpronin.github.io"` и выполнить `node build.mjs`. Это создаст корректные canonical/hreflang и sitemap.
3. Загрузить содержимое этой папки в корень репозитория. `build.mjs`, `site.json` и README тоже можно хранить там; секретов в них быть не должно.
4. Settings → Pages → Deploy from a branch → main → / (root) → Save.
5. Дождаться завершения публикации и проверить главную, русский язык и страницы исследований по внешнему адресу.

GitHub Pages не гарантирует вечное хранение или неизменность бесплатного тарифа. Храните копию исходников. Сайт переносится на любой статический хостинг.

Тексты первой версии подготовлены по публичным профилям и исследованиям автора. Rank-Turbulence Delta обозначена как журнальная статья; From Genes to Tokens — как препринт и выступление на DH2026.
