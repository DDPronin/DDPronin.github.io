# Дмитрий Пронин — двуязычный исследовательский сайт

Готовый статический сайт: `index.html` — английская главная, `ru/index.html` — русская. Для каждого из двух исследований есть отдельный разбор на обоих языках; резюме находится в `cv/` и `ru/cv/`. Всего восемь страниц. Все страницы уже сгенерированы; сайт работает без сборки, базы данных и внешних библиотек.

Сайт опубликован: https://ddpronin.github.io/ и https://ddpronin.github.io/ru/.

## Изменения

- Тексты и ссылки находятся в `build.mjs`.
- Содержание обеих веб-версий резюме находится в `cv.json`. Файлы для скачивания — в `cv-files/`; при изменении резюме нужно также обновить соответствующие Word- и PDF-файлы.
- Оформление — `assets/style.css`.
- Публичный адрес и добровольно выбранный email — в `site.json`. Поле email можно оставить пустым; в контактах уже указаны публичные Telegram и профиль ВШЭ.
- После изменения выполнить `node build.mjs` в этой папке. Требуется только Node.js, без установки пакетов.

## Публикация на GitHub Pages

1. В аккаунте DDPronin создать публичный репозиторий `DDPronin.github.io`, если такого репозитория ещё нет. Если есть — сначала сохранить и проверить его содержимое.
2. В `site.json` указать `"url": "https://ddpronin.github.io"` и выполнить `node build.mjs`. Это создаст корректные canonical/hreflang и sitemap.
3. Загрузить содержимое этой папки в корень репозитория. `build.mjs`, `site.json` и README тоже можно хранить там; секретов в них быть не должно.
4. Settings → Pages → Deploy from a branch → main → / (root) → Save.
5. Дождаться завершения публикации и проверить главную, русский язык и страницы исследований по внешнему адресу.

GitHub Pages не гарантирует вечное хранение или неизменность бесплатного тарифа. Храните копию исходников. Сайт переносится на любой статический хостинг.

## Содержимое и атрибуция

Тексты подготовлены по публичным профилям, исследованиям и предоставленному автором академическому резюме. Rank-Turbulence Delta обозначена как журнальная статья; From Genes to Tokens — как препринт и выступление на DH2026. Соавтор Евгений Казарцев указан на страницах исследований и в библиографии. Описание возможностей СОЦИОЛИТа основано на https://sociolit.ru/, личный вклад — на предоставленном резюме. Статус публикации о СОЦИОЛИТе «в печати» сохранён в соответствии с резюме и записью https://publications.hse.ru/chapters/1025704970.

Публичный контакт `i@ddpronin.ru` и фотография добавлены по запросу автора. Фотография переведена из HEIC в JPEG, метаданные местоположения удалены. Кадрирование для первого экрана выполняется средствами CSS.

Научные иллюстрации скопированы без изменений из репозиториев Дмитрия Пронина, со ссылками на источники:

- `assets/rank-russian.png`: https://github.com/DDPronin/Rank-Turbulence-Delta/blob/main/figures/lexical_shift_RU_unigram.png
- `assets/gwas-tolstoy.png`: https://github.com/DDPronin/GWAS-stylometry/blob/main/imgs/manhattan_tolstoy.png

У научных графиков сохраняются условия лицензирования исходных проектов; сайт не присваивает им новую лицензию. Выбор системных шрифтов устраняет зависимость от внешних сервисов шрифтов.
